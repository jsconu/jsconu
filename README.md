## Ondatrace

I'm building Ondatrace for PMOs. It reads the tools a PMO already uses (Jira, Slack, Teams, calendars and meeting transcripts) and keeps one shared memory of every project. Each project manager and the PMO leader sees the few things that need them, with the evidence behind each one.

After years leading programs, I've found the problems that sink projects rarely live in the plan. A date moves in one tool. A promise sits in someone's email. A decision gets made in a meeting and never written down. Each project manager's own AI assistant only sees their part. Ondatrace gives the whole PMO the same picture.

Ondatrace is in a private pilot.
